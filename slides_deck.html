Does complexity

Kalshi (CFTC-regulated event contracts) and Polymarket (on-chain) often disagree on the same event.

Headline Results · Per-trade alpha & Sharpe

Simpler dominates.

Per-trade alpha (basis points) · canonical headline.json · seed=42 · $100 position · 6,802 train / 1,673 test
Per-trade alpha = (P&L / num_trades) / position_size. Position-size-invariant; standard quant pitch metric. PPO + autoencoder canonical figure replaces a non-reproducible legacy claim (see 17-02-PPO-DIAGNOSTIC.md).
Per-pair Sharpe
≈ 3.2

Annualized, 144 pairs as independent bets (Table 8).

Every window profitable for every ML model.

Linear Regression wins on Sharpe (0.501) and alpha (15 bps). PPO + autoencoder collapses to 0.5 bps — 30× less edge for far more compute.

Gap 01

Win rate halved (57% → 32%). Time-stop exits and a wider live universe drag the rate down.

Gap 02

Live and backtest sim are anti-correlated: same model predictions, opposite trade direction (paper §5.9).

Gap 03

Crypto bleeds live (−$13 / 19.6% win on 2,438 trades); oil edge not yet validated post Phase 15 fix.

Backtests validate ranking — they don't validate real-world execution.

01

At 6,802 rows, complexity is a liability, not an edge.

The alpha is in the matching pipeline and asset class — not the models.

Engineering bugs masquerade as model failures.
