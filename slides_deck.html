Problem Statement

Does complexity
actually help?

A · The setup

Kalshi (CFTC-regulated event contracts) and Polymarket (on-chain prediction market) often disagree on the same event.

B · The question

Do RNNs, RL, and autoencoders predict price convergence better than plain regression?

C · Why it matters

Polymarket processed over $1B in 2024 elections — a practical answer for a fast-growing ecosystem.

Methodology

Four model tiers,
identical evaluation.

Tier 1 Regression Linear Regression  ·  XGBoost
Tier 2 Sequence GRU  ·  LSTM  ·  TFT
Tier 3 Reinforcement PPO (raw features)
Tier 4 RL + Anomaly PPO + autoencoder filter
6,802 train  ·  1,673 test rows  ·  144 matched pairs  ·  59 features (13 microstructure)
Sentence-transformer matching · 10-rule structural quality filter · Content-addressed pair IDs.

Conclusions

What we learned.

01

At 6,802 rows, complexity is a liability, not an edge.

02

The alpha is in the matching pipeline and asset class — not the models.

03

Engineering bugs masquerade as model failures.
