**Three-way split function:**
```python
def temporal_split(df: pd.DataFrame, train_frac: float = 0.85):
    """Split df chronologically. df must already be sorted by time_idx/timestamp."""
    n = len(df)
    cut = int(n * train_frac)
    return df.iloc[:cut].reset_index(drop=True), df.iloc[cut:].reset_index(drop=True)
```
Apply to each pair group separately to preserve per-pair chronological ordering, OR sort globally by time_idx and split — RESEARCH.md says "earliest 85% of train.parquet". Use global sort by time_idx (simpler, consistent with verify_headline.py's sort order).

**Bootstrap CI function:**
```python
def bootstrap_delta_pnl(preds_config, preds_baseline, actuals, n_boot=1000, fee=0.02, rng=None):
    """Paired bootstrap CI for delta-P&L (config - baseline)."""
    rng = rng or np.random.default_rng(42)
    n = len(actuals)
    deltas = []
    for _ in range(n_boot):
        idx = rng.integers(0, n, size=n)
        pnl_config = simulate_pnl(preds_config[idx], actuals[idx], fee)["pnl"]
        pnl_base = simulate_pnl(preds_baseline[idx], actuals[idx], fee)["pnl"]
        deltas.append(pnl_config - pnl_base)
    arr = np.array(deltas)
    return float(np.percentile(arr, 2.5)), float(np.percentile(arr, 97.5)), arr
```
