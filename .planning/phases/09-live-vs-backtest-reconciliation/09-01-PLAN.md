    - load_closed_positions(db_path: str | Path) -> list[dict]

    - filter_window(positions: list[dict], start: str = "2026-04-11", end: str | None = None) -> list[dict]
      Excludes any position where exit_reason == "force_close_schema_fix".
      Excludes positions where entry_time < start (ISO comparison is safe since format is ISO 8601 UTC).
      If end provided, excludes positions where entry_time > end.

    - run_shadow_simulation(positions: list[dict], bars_path: str | Path, models_dir: str | Path) -> list[dict]
      For each position:
        1. Look up entry bar: bars[(bars["pair_id"]==pair_id) & (bars["timestamp"]<=entry_ts)].nlargest(1,"timestamp")
        2. If no bar found: record matched=False, skip simulation for that position.
        3. Run compute_derived_features(pd.DataFrame([entry_bar])).fillna(0.0)
        4. Align to feature_columns from models_dir/feature_columns.json using:
             X = row_df[[c for c in feature_columns if c in row_df.columns]]
        5. lr_pred = float(lr_model.predict(X)[0])
           xgb_pred = float(xgb_model.predict(X)[0])
           avg_pred = (lr_pred + xgb_pred) / 2.0
        6. actual_change = pos["exit_spread"] - pos["entry_spread"]
        7. result = simulate_profit(np.array([avg_pred]), np.array([actual_change]), threshold=0.02)
        8. Return dict with: pair_id, kalshi_ticker, direction, exit_reason, category,
           live_pnl (pos["realized_pnl"]), sim_pnl (result["total_pnl"]),
           lr_pred, xgb_pred, avg_pred, actual_change, matched=True
      Note: category uses derive_category_from_ticker(pos["kalshi_ticker"]) — NOT pair_id.

    - build_summary(matched_results: list[dict]) -> dict
      Returns: live_total_pnl, sim_total_pnl, tracking_error (live - sim),
               matched_count, unmatched_count, gap_metric (unmatched/total).

    - category_breakdown(matched_results: list[dict]) -> dict[str, dict]
      Groups by category. Each group: live_pnl_sum, sim_pnl_sum, count, tracking_error.
