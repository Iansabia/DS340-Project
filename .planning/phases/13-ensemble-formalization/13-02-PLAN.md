**PER-MEMBER FEATURE ROUTING (RESEARCH.md Pitfall 2 mitigation):**

The EnsemblePredictor's `fit(X, y)` and `predict(X)` receive a SINGLE X input, but mixed ensembles need different inputs per member. Handle this at the experiment-script level, NOT inside the ensemble class. Implementation:

```python
def fit_mixed_ensemble(members, X_flat, X_seq, y):
    """Fit each member on its appropriate feature set."""
    for m in members:
        X_for_member = X_seq if type(m).__name__ in {"GRUPredictor", "LSTMPredictor"} else X_flat
        m.fit(X_for_member, y)

def predict_mixed_ensemble(members, weights, X_flat, X_seq, concordance):
    """Predict with each member on its appropriate feature set, then combine."""
    preds = []
    for m in members:
        X_for_member = X_seq if type(m).__name__ in {"GRUPredictor", "LSTMPredictor"} else X_flat
        preds.append(m.predict(X_for_member))
    stacked = np.stack(preds)  # (n_members, n_rows)
    if concordance == "strict":
        agree = np.all(np.sign(stacked) == np.sign(stacked[[0]]), axis=0)
        return np.where(agree, np.average(stacked, axis=0, weights=weights), 0.0), preds
    return np.average(stacked, axis=0, weights=weights), preds
```

CONCORDANCE AUDIT FUNCTION (ENSM-03) — implement as inner function concordance_audit(member_preds_dict, actuals, fee=0.02):
- member_preds_dict: {"lr": ndarray, "xgb": ndarray, ...} — predictions from each member independently (pre-fitted)
- stacked = np.stack(list(member_preds_dict.values()))   # (n_members, n_rows)
- avg_pred = stacked.mean(axis=0)
- agree_mask = np.all(np.sign(stacked) == np.sign(stacked[[0]]), axis=0)
- unfiltered = simulate_pnl(avg_pred, actuals, fee)
- filtered = simulate_pnl(np.where(agree_mask, avg_pred, 0.0), actuals, fee)
- rejected = simulate_pnl(np.where(~agree_mask, avg_pred, 0.0), actuals, fee)
- rejection_rate = 1.0 - filtered["num_trades"] / max(unfiltered["num_trades"], 1)
- flag = rejected["pnl"] > 0
- If flag: print WARNING with exact rejected P&L (P4 concordance trap)
- Return dict with all fields
