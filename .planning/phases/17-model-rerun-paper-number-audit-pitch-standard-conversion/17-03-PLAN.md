The 3 new checks (REPL-06):

**Check REPL-06a: Abstract contains "Sharpe" or "per-trade Sharpe".** The abstract MUST mention Sharpe — the new pitch-standard headline.

```bash
echo "== REPL-06: Pitch-standard headlines =="
ABS_SHARPE=$(awk '/^## Abstract/{f=1;next} /^---$/{if(f)exit} f' "$PAPER" | grep -cE "[Ss]harpe")
check_ge "abstract_mentions_sharpe" 1 "$ABS_SHARPE"
```

**Check REPL-06b: Abstract contains a Sharpe value (decimal between 0.0 and 10.0).** Mentioning "Sharpe" without a number is hand-wavy; the abstract must cite a specific value.

```bash
ABS_SHARPE_VAL=$(awk '/^## Abstract/{f=1;next} /^---$/{if(f)exit} f' "$PAPER" | grep -cE "[Ss]harpe[^0-9]{1,30}[0-9]\.[0-9]+|[0-9]\.[0-9]+[^0-9]{1,30}[Ss]harpe")
check_ge "abstract_cites_sharpe_value" 1 "$ABS_SHARPE_VAL"
```

**Check REPL-06c: Every dollar P&L claim has a Sharpe or bps companion in the same paragraph.** This is the strongest discipline: a future writer cannot regress to a dollar-only headline. The check uses awk paragraph extraction (paragraphs separated by blank lines), then for each paragraph containing `$X.YY` or `+$X.YY`, asserts the same paragraph also contains `Sharpe` or `bps`.

```bash
# Paragraphs with a dollar amount but NO Sharpe/bps in the same paragraph = violations.
ORPHAN_DOLLARS=$(awk 'BEGIN{RS=""; FS="\n"} {
  if ($0 ~ /\$[0-9,]+(\.[0-9]+)?/ && $0 !~ /[Ss]harpe/ && $0 !~ /bps/) {
    print NR
  }
}' "$PAPER" | wc -l | tr -d ' ')
check "orphan_dollar_paragraphs" 0 "$ORPHAN_DOLLARS"
```

Note: the orphan check has a known limitation — paragraphs that legitimately quote dollar amounts in supplementary tables without commentary (e.g., the Table 2 row text) may flag false positives. If the false-positive rate is too high, narrow the awk filter to only paragraphs in §1 / §5 / §8 / Abstract using a section-aware extractor:

```bash
# Tighter version — only check headline sections.
ORPHAN_DOLLARS=$(awk '
  BEGIN { RS=""; FS="\n" }
  /^## Abstract/ || /^### 5\.1/ || /^### 5\.8/ || /^## 8/ || /^## Conclusions/ { in_headline = 1 }
  /^## [A-Z]/ && !/^## Abstract/ && !/^## 8/ && !/^## Conclusions/ { in_headline = 0 }
  in_headline && $0 ~ /\$[0-9,]+(\.[0-9]+)?/ && $0 !~ /[Ss]harpe/ && $0 !~ /bps/ { print NR }
' "$PAPER" | wc -l | tr -d ' ')
```

Use whichever version yields zero false positives against the just-updated paper. Run `bash scripts/check_paper.sh` after each candidate awk and verify it passes.
